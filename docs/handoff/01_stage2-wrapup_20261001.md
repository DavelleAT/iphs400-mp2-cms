## Things to know before you start

- **The transcript guard:** `git config core.hooksPath .githooks` has to be
  set in each clone. `.githooks/pre-commit` runs
  `scripts/redact_transcripts.py --staged` and refuses a commit if a staged
  transcript still holds a password, a secret from `.env`, or the author's
  email. The SessionEnd hook already saves new transcripts redacted. Run
  `python3 scripts/redact_transcripts.py` to redact the saved ones again.
- **Rubric D5 (no secrets in history):** a grep of history finds the demo
  passwords from `.env.example` and the tests. These are fixture values, not
  real credentials. Say that in the report rather than rewriting history.
- **Rubric B3 (closing commits as ticket slices):** on a strict reading, only
  12 of the 24 closing commits are a whole ticket's slice. Look at
  `git log --grep "Closes #"` before writing the report, and explain the
  commits that aren't.
- **Never edit `site/` by hand.** Redeploy with `cms publish` then
  `cms deploy`, using the real `cms.db`. Do browser checks on a scratch
  instance instead: `CMS_DATABASE`/`CMS_UPLOADS` in a scratch folder, and
  `scripts/seed_demo.py` with the passwords taken from the environment.
- The context hook warns at 30% and auto-compacts at 40%. This wrap-up
  session was the first to compact (see `docs/process/compaction-log.md`).
